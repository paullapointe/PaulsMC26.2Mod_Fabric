Pauls Minecraft Mod

This is set of mostly random custom blocks, items and enchantments, for fun, that we like to use on our server.

It's currently not separated into different themed mods, but includes:
- Blocks for automating crafting and smelting
- Nice looking pillars
- Enchantable magic staffs
- Redstone receiver, spawner
- Dinner plates, scrambled eggs and waffles
- other unfinished random stuff.
